一、OpenCub API 是什么？

OpenCub API 是一个面向 GPT、Codex、Claude、绘图模型等服务的 API 中转站。

用户可以在 OpenCub API 后台创建自己的 API 密钥，然后把密钥配置到不同的软件或插件里使用。常见使用场景包括：

开发工具

Codex CLI、Codex 官方客户端、VS Code、Cursor、Windsurf 等。

AI 客户端

Cherry Studio、Open WebUI、其他 OpenAI 兼容客户端。

模型服务

GPT、Claude、图像生成等模型能力。

二、使用前需要准备什么？

正式使用前，建议先完成账号、余额和 API Key 三件事。

注册并登录 OpenCub API

打开官网 opencub.uk，注册账号并登录后台。

兑换余额或购买兑换码

如果手里有兑换码，进入后台兑换到账户余额；如果没有，可前往 购买地址 购买。

创建 API 密钥

进入后台的 API 密钥页面，创建一个新的 API Key。后续配置 Codex、Claude Code、Cherry Studio、Open WebUI 等客户端时都会用到。

保存通用配置信息

记住 API 请求地址、API Key、模型名称。模型名称建议从后台复制，避免大小写或空格错误。

安全提醒：API Key 等同于账户调用凭证，请勿发到公开群、论坛、GitHub 仓库或任何公开位置。发现泄露后应立即在后台删除旧 Key 并重新创建。

四、Codex 的常见使用方式

Codex 常见有三种使用方式，新手可以优先选择图形界面，开发者可选择 CLI 或编辑器插件。

1. Codex 官方客户端

适合不想折腾命令行的新手用户。进入 Codex 官网后，按官方说明下载和使用。

2. Codex CLI

适合经常使用终端的开发者。配置好 API 地址和 Key 后，可在终端中直接调用。

3. 编辑器插件

适合在 VS Code、Cursor、Windsurf 等编辑器里直接使用。安装插件时请认准官方或可信来源。

注意：不同客户端的字段名称可能不一样，例如 API Base URL、Base URL、Endpoint、请求地址，本质都是填写 OpenCub API 请求地址。

五、如何通过 CC-Switch 切换到 OpenCub API？

如果你想让 Codex 或相关工具使用 OpenCub API，可借助 CC-Switch 新增并启用供应商配置。

下载 CC-Switch

根据自己的系统下载 Windows / macOS / Linux 版本。统一打开 GitHub Releases 页面，找到自己系统对应的 Windows / macOS / Linux 版本下载：https://github.com/farion1231/cc-switch/releases

在后台创建 API Key

进入 OpenCub API 后台，创建一个新的 API Key，后面会填入 CC-Switch。

新增 OpenAI 供应商

打开 CC-Switch，选择 OpenAI 图标，点击右侧加号，新增一个供应商配置。

填写供应商信息

供应商名称填 opencubapi，API Key 填后台创建的密钥，API 请求地址填 https://opencub.uk，模型名称推荐填写 gpt-5.5，也可以按后台显示填写。

添加、启用并重启客户端

点击添加，返回上一页后点击启用，然后重启 Codex 或对应客户端。重启后会通过 OpenCub API 进行调用。

七、常见客户端使用方法

1. Cherry Studio

  1. 下载并安装 Cherry Studio。
  2. 打开设置，选择模型服务商或自定义服务商。
  3. 格式选择 OpenAI 或 OpenAI 兼容格式。
  4. API 地址填写 https://opencub.uk。
  5. API Key 填写后台创建的密钥。
  6. 点击“获取模型”，选择需要使用的模型后保存。

2. Open WebUI

  1. 进入 Open WebUI 设置页面。
  2. 找到连接、外部模型、OpenAI API 或类似入口。
  3. Base URL 填写 https://opencub.uk。
  4. API Key 粘贴自己的 OpenCub API 密钥。
  5. 保存配置，刷新模型列表，选择需要的模型开始使用。

八、绘图工作台使用方法

绘图工作台用于图像生成任务。使用前请先在 OpenCub API 后台确认账号支持图像生成模型，并单独创建 image 生图 API Key。

  1. 进入绘图工作台。
  2. 模式选择 作图。
  3. API 地址填写 https://opencub.uk。
  4. 中转密钥填写单独创建的 image 生图 API Key。
  5. 模型选择后台支持的绘图模型，例如 gpt-image-2。
  6. 分辨率只能选择 2K 或 4K，其他配置按需选择。
  7. 保存配置后，输入提示词并测试生成。

十、模型收费说明

不同模型的收费标准不同。一般来说，GPT、Claude、图像生成等模型会有各自的计费规则，高级模型或特殊通道的费用通常高于普通模型。

倍率怎么看？

倍率越低，消耗越少；同样余额下可使用的 Token 越多。示例：10 ÷ 0.25 = 40。

如何避免余额消耗过快？

调用前先确认模型倍率，不要误选高倍率模型；长文本、批量任务、图像任务会更快消耗余额。

重要：后台价格、倍率、缓存策略、可用模型可能会调整。遇到和本文档不一致的情况，以后台实时展示为准。

十一、新手常见问题

1. API 地址应该填什么？

填写 OpenCub API 的请求地址：https://opencub.uk。不要多加空格，不要写成购买地址，也不要把后台页面地址误填到 API 地址里。

2. API Key 从哪里来？

API Key 需要在 OpenCub API 后台创建。创建后复制出来，填入对应软件的 API Key、Token、Secret Key 或密钥位置。

3. 为什么配置后不能用？

请按顺序检查：API 地址是否正确、API Key 是否复制完整、账户余额是否充足、模型名称是否正确、是否已保存或启用配置、客户端是否已重启、当前模型是否在后台支持。

4. 为什么获取不到模型？

常见原因包括 API Key 填错、API 地址填错、网络连接异常、客户端不支持自动拉取模型、账号余额不足或权限不足。可先手动填写模型名称测试。

5. 为什么调用失败或报错？

常见原因包括模型名称不支持、余额不足、请求地址错误、软件没有重启、选择了不支持的模型格式、中转站维护或通道异常。可把报错内容、调用时间、模型名称发给售后处理。

6. 余额扣费和我预期不一样怎么办？

先查看后台账单记录、调用模型、倍率、输入输出 Token、是否开启缓存或特殊通道。若仍有疑问，可把调用时间、模型名称、客户端名称和相关配置发给售后核对。

十二、推荐使用流程

新手建议按下面顺序操作，能减少大部分配置问题。

注册 OpenCub API

进入官网 opencub.uk 注册并登录后台。

购买或兑换余额

通过兑换码或 购买入口 完成充值。

创建 API Key

在后台 API 密钥页面新建密钥，并妥善保存。

选择客户端

根据需求选择 Codex、Claude Code、Cherry Studio、Open WebUI 或绘图工作台。

填写地址和密钥

API 地址填 OpenCub API 请求地址，API Key 填后台创建的密钥。

保存、获取模型、开始使用

保存配置，获取或手动填写模型，选择模型后开始调用。

一句话总结：先在 OpenCub API 创建密钥，再把 API 地址和 API Key 填到对应软件里，保存启用后即可使用。
